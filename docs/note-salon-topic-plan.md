# 📝 note集客ネタ企画書 — エステサロン集客メディアでリード獲得（第一歩）

> 目的の全体像: 「ネタ収集 → 企画 → ライティング → noteへの自動投稿」パイプラインで、
> リード社の新規クライアント（エステサロンのオーナー・経営者）を獲得する。
> 本書はその**前段**として、①200本以上のネタを量産できる企画の枠組み と
> ②山田さんのアイデアを貯める仕組み を定義する。執筆・自動投稿の実装は片岡さんへ委託予定であり、
> 本書はその引き渡し資料を兼ねる。
>
> 実データはNotion、仕様・プロンプトは本リポジトリで版管理（TOOL-14/15と同じ運用パターン）。

## 1. ターゲットと狙い

- **読者** = エステサロンのオーナー・経営者（メインは「集客に伸び悩む個人サロン」「スタッフ数名の小規模店」）
- **提供価値** = 集客ノウハウ（脱ホットペッパー・SNS・LINE・MEO・広告・リピート改善）
- **出口（CTA）** = リード社の支援メニュー（広告運用・LINE構築・AI活用支援など。詳細はアイデアDB No.4 の回答で確定）
- **なぜnoteか** = ドメインが強く検索上位を取りやすい、少人数運用でもリード獲得実績が多い媒体
  （BtoB企業が広告費ゼロで月15リード等の事例あり。§5 出典参照）

## 2. ネタ量産マトリクス（200本以上を担保する枠組み）

3軸の掛け合わせでネタを量産する。4×10×8=320通りの組合せが母集団となり、
品質選別後も200本以上を確保できる。

- **軸A ペルソナ（サロンの状況）4種**
  ①開業準備〜1年目 / ②集客に伸び悩む個人サロン / ③スタッフ数名の小規模店 / ④2店舗目・多店舗展開期
- **軸B テーマカテゴリ 10種**（＋戦略・その他）
  ホットペッパー依存脱却 / Instagram・SNS運用 / LINE公式・リピート導線 / MEO・Googleマップ /
  Meta広告・リスティング / 口コミ・紹介 / リピート率・LTV / 客単価・メニュー設計 /
  カウンセリング・成約率 / 予約管理・業務効率化（AI活用含む）
- **軸C 切り口フォーマット 8種**
  How-to / 事例 / NG集 / チェックリスト・テンプレ / データ・トレンド / 比較・選び方 / Q&A / 季節・イベント

1ネタ＝「軸の組合せ＋仮タイトル＋狙い1行」で1レコード。ネタ源は次の2系統:
1. **Web調査**（検索サジェスト・業界メディア・競合note・トレンド）→ 一般ニーズを網羅
2. **💡山田アイデアDB**（山田さんの実体験・顧客事例・持論）→ 記事の独自性と一次情報を担保

### 📝 noteネタDB（1レコード＝1記事ネタ）

| プロパティ | 型 | 内容 |
|---|---|---|
| Name | title | 仮タイトル |
| ペルソナ | select | 軸A 4種 |
| カテゴリ | select | 軸B 10種＋戦略・その他 |
| 切り口 | select | 軸C 8種 |
| ステータス | select | 候補 → 山田OK → 企画確定 → 執筆済 → 投稿済（＋見送り） |
| 優先度 | select | 高 / 中 / 低（検索ニーズ×専門性×CTA接続の強さ） |

## 4. 運用フロー

```
【ネタを貯める】
Web調査 ─────────────┐
                      ├→ 📝noteネタDB（候補）→ 山田さん確認（山田OK/見送り）→ 企画確定
山田さんの音声回答 ──┘
   ↑
🎙️ヒアリングループ（docs/note-salon-hearing-prompt.md）
 Claudeが番号付き質問を提示 → 山田さんがAqua Voiceで「No.〇〇、…」と回答
 → Claudeが要点整理して💡アイデアDBへ保存（回答済）→ 記事になりそうなら📝ネタDBへ（ネタ化済）

【書く・出す（片岡さん委託範囲・将来）】
📝ネタDB（企画確定）＋💡アイデアDB（回答本文）→ ライティング → note下書き投稿
```

- ヒアリングは週1回・5〜10問ペース想定（50問≒1ヶ月で完走）。移動中の音声入力でOK。
- サンプル50本の「山田OK/見送り」振り分け後、傾向を反映して200本超へ拡張（`docs/note-salon-topics.md` §拡張手順）。

## 5. Web調査サマリ（2026年7月時点・タイトル/狙い設定の根拠）

- **脱ホットペッパーが最大の関心事**: 2026年2月のHPB改定もあり「依存リスクと脱却」の情報ニーズが強い。
  脱却後6ヶ月で自社予約率7割の事例、自社サイト＋Googleマップ＋Instagram＋LINEの組合せが定石。
  - https://salonshuukyaku.com/hpb-kaiaku/ / https://beauty-pos.jp/knowledge-reason/hotpepper-dependence-break/ / https://m-hands.net/blog/4961/
- **リピートが業界共通の弱点**: 新規の3ヶ月リピート率は平均17%（HPBアカデミー調べ）。エステの平均リピート率は20〜30%。
  LINE公式導入でリピート率40%→65%の改善事例。
  - https://biz.relax-job.com/esthetic-client-attraction / https://suzukinatsuka.com/repeat-rate-esthetic-average/
- **Instagramは「フォロワー数」から「ファン化・導線」へ**: リール優先表示・マップ検索・DM予約が2026年のトレンド。
  GBP最適化＋週3投稿で自然流入2.5倍・広告費ゼロで月30件の新規予約という小規模サロン事例。
  - https://ai-bouz.com/salon-instagram2026/ / https://meiseisouken.jp/beauty-salon-marketing-trends-2025/ / https://s--line.co.jp/beauty-salon-instagram-marketing/
- **MEOはAI検索対応（NAP統一）が新論点**: 全媒体でサロン名・住所・電話の完全統一が必須に。
  - https://ai-bouz.com/salon-marketing-2026/ / https://churaweb.net/meo/esthe-salon-marketing/
- **noteはBtoBリード獲得に実績**: 50名規模のBtoB企業が6ヶ月でPV300→3万・広告費ゼロで月15リード。週1〜2本の質重視が現実的ペース。
  - https://note.com/stock_value0407/n/nd1b9cd676f2d / https://www.comnico.jp/we-love-social/note_matome

## 6. 初期データとセットアップ

- 質問50問: `docs/note-salon-questions.md`（カテゴリ横断・山田さんの一次情報を引き出す設計）
- サンプルネタ50本: `docs/note-salon-topics.md`（マトリクス準拠・分布サマリ付き）
- **セットアップ手順**: `docs/note-salon-setup-prompt.md` を対話セッションで1回実行する。
  ※`notion-create-database`（プロパティ付きDB作成）だけがMCP承認を要するため、自動セッションでは
  実行不可（トリガー設定時と同じ制約）。行ページ・質問・ネタのデータはすべて準備済みで、
  実行時にDB作成の許可を1〜2回承認するだけ。
- セットアップ後、ヒアリングは `docs/note-salon-hearing-prompt.md` を新しいセッションに貼るだけで開始できる。

## 7. 将来パイプラインとの接続（片岡さんへの引き渡しポイント）

- **執筆パイプラインの入力** = 📝ネタDBの `ステータス='企画確定'` レコード（仮タイトル・ペルソナ・切り口・狙い）
  ＋ 元アイデアrelation先の💡アイデアDB回答本文（山田の一次情報。記事の独自性の源泉）。
- **出力** = note記事。事前調査の結果（片岡さん調べ）: 下書きの自動投稿は可能 / 見出し・太字までは工夫すれば可 /
  画像の自動挿入はハードル高。→ MVPは「下書き自動投稿＋人が画像・最終確認して公開」の半自動が現実的。
- **投稿後の運用**（将来）: 投稿済レコードにnote URLとPV/スキ数を記録するプロパティを追加し、
  反応の良いカテゴリ・切り口へネタ生成を寄せる改善ループを回す。
- **書き方のガードレール**: 薬機法・景表法まわりの表現（アイデアDB No.5 の回答を反映）/
  クライアント事例の実名可否（No.6）を執筆プロンプトに組み込むこと。
