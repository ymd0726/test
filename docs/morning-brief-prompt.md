1通で「今日の要対応＋昨日の動き＋放置/取りこぼしアラート」を届ける“朝の司令塔”。

## ルーチン設定
- name: `☀️ 朝ブリーフィング（→#prv）08:00 JST`（既存🅱を置換 or 新規）
- スケジュール: 毎日 08:00 JST（cron `0 23 * * *` UTC）
- 実行環境: Claude Code ルーチン（新セッション方式）／コネクタ: **Notion ＋ Slack**
