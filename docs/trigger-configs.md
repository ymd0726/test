【データソース】

【STEP① 取り込み（差分のみ→生ログ層）】

1. 本日新規の生ログのうち 種別∈[論点・課題/タスク/リスク] に内容から課題フラグを付与し、対応ステータス=未着手（未設定時）：
   重要度🔴高or経営影響大→重要課題 / 判断に迷う論調→悩み中・要相談 / 期限が近い・超過→期限リスク・遅延 / 承認・決裁待ち→要決定。
2. 自動クローズ: 対応ステータス≠完了かつ課題フラグ有の既存レコードを本日新規の生ログ/Slackと突合。明確な「完了/解決済み/対応済み/停止決定」の言及がある場合のみ 対応ステータス=完了・解決ソース=根拠URL を記録し、対象案件の集約「8.変更ログ」に1行残す。曖昧な言及ではクローズしない（保守的判定）。完了済みが未解決で再言及されたら対応中に戻す。
