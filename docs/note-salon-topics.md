1. 山田さんが50本のステータスを「山田OK / 見送り」に振り分ける（Notion上で操作）
2. 「山田OK」の傾向（ペルソナ・切り口の偏り）と、💡山田アイデアDBの回答済みレコードをインプットに、残りのマトリクス組合せ（4×10×8=320通りのうち未使用分）から150本以上を追加生成する
