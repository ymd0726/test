### URL表記ルール（Slackリンク記法・共通）
Slack本文にURLを出すときは **必ず Slack mrkdwn のリンク記法 `<URL|表示テキスト>`** を使い、
生URLをそのまま貼らない（生URLだと行が長くなり、ページ名も分からないため）。

- 表示テキストは既定で `link`。例：`<https://app.notion.com/p/xxxx|link>`
- 実際に送るのは **URLを埋め込んだ完成形**。`<ソースURL|link>` のようなプレースホルダを
  そのまま送信してはいけない（`ソースURL` を実URLに置換すること）。
- `|` の前後に空白を入れない。`<`〜`>` の外に同じURLを重ねて書かない。
- Notionページへのリンクは、受け取った人がそのページを開いて手動でステータス変更等を
  行う導線になる（例：「対応ステータス」の手動切り替え）ため、**リンク化は必須**。

### 実装メモ
- 送信は Slack MCP `slack_send_message`（`channel_id` 指定、テキストのみ）。
- まずは `slack_send_message_draft`（下書き）で内容確認 → 問題なければ本送信、という運用も可能。

### 立ち上げ手順（ドライラン → 本稼働）
1. **手動ドライラン**：トリガーを作るか、または本セッションでパイプラインを1回手動実行。
   - 少数の未抽出議事録だけで STEP① → ② → ③(下書き) を流し、生ログ・集約・通知文を目視確認。
2. **冪等性チェック**：同じ入力で2回流し、二重登録・本文崩れが無いか確認。
3. 問題なければ `create_trigger` で日次スケジュールを有効化。
4. 旧 03:00/03:30 スキルは停止済みのため衝突なし（本トリガー1本に統合）。
