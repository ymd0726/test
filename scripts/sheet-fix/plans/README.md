# パッチプラン置き場

集計表のセル・数式修正は、ここに 1 修正 = 1 JSON でプランを置いてから
GitHub Actions「集計表 セル修正（sheet-fix）」で dry-run → apply の順に実行する。
コミットされたプランがそのまま修正の監査ログになる。

## ファイル名

`YYYY-MM-DD_<案件キー>_<内容>.json`（例: `2026-07-19_jdem_判定式修正.json`）

## 形式

```json
{
  "sheet": "スプレッドシートID または URL",
  "tab": "meta_total",
  "note": "何のための修正か（依頼の要約）",
  "edits": [
    {
      "cell": "CD5",
      "expectedBefore": "現在入っている値（数式なら =IF(... のまま）",
      "after": "変更後の値・数式",
      "note": "このセルを変える理由"
    }
  ]
}
```

## ルール

- `cell` は**単一セルのA1表記のみ**（行・範囲指定は不可）
- `expectedBefore` は必須。現在値（数式レンダー or 表示値）と一致しない編集が
  1件でもあれば**全編集が中止**される（列ズレ事故防止）
- 現在値の検証をどうしても省く場合のみ `"allowAnyBefore": true` を明示（非推奨）
- cr-id が入っているセルを空にする編集は拒否される（ID行クリア厳禁）
